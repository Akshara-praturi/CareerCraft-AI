# 🚀 CareerCraft AI

An AI-powered Career Assistance Platform built using React.js, Flask, SQLite, Tailwind CSS, and AI-powered resume analytics.

## ✨ Features

### 📄 Resume Builder

* Professional Resume Creation
* Live Resume Preview
* PDF Resume Download
* Multiple Job Role Support

### 🤖 ATS Resume Analyzer

* Resume PDF Upload
* ATS Score Calculation
* Skill Extraction
* Missing Skills Detection
* Resume Improvement Suggestions

### 📊 Dashboard Analytics

* ATS Score Tracking
* Skill Match Visualization
* Career Insights Dashboard

### 💼 Job Portal

* Browse Job Listings
* Job Details View
* Skill Requirement Analysis

## 🛠 Tech Stack

### Frontend

* React.js
* Vite
* Tailwind CSS
* Recharts
* Framer Motion

### Backend

* Flask
* Flask-CORS
* SQLAlchemy

### Database

* SQLite

### Libraries

* PyPDF2
* jsPDF
